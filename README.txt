SCHONE START – RUINEKERK APP V1

Bestanden:
- index.html
- locaties.json
- locaties/ruinekerk.html
- locaties/skarpet.html

De index.html bevat geen locatiegegevens. Hij leest altijd locaties.json.
De verhalen worden uit de afzonderlijke bestanden in locaties/ geladen.

Testfuncties:
- interactieve kaart
- virtuele testpositie
- echte GPS
- alle locaties op kaart
- 500 meter overzicht
- 250 meter verhaalzone

De virtuele testpositie gebruikt de Ruïnekerk-coördinaten.
De twee locatiecoördinaten zijn opgenomen als geverifieerde/verifieerde-nabij-ingang punten uit de eerdere locatiecontrole.
