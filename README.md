# Reisblik 8.6.6

- Mijn reisdag ondersteunt een inclusieve datumrange: Datum van en Datum t/m.
- De bestaande datumselectie blijft compatibel met eerdere opgeslagen enkele datums.
- Toon op kaart gebruikt alle bezochte locaties binnen de gekozen periode.
- De reisdagkaart is iets uitgezoomd zodat geselecteerde locaties overzichtelijker in beeld komen.
- De permanente knop Naar boven uit 8.6.5 blijft behouden.
- Bestaande zoek-, extra-info-, spraak-, backup- en restorefuncties blijven behouden.


Reisblik 8.6.9: veld “Belevenis” uit het Extra informatie-venster verwijderd. Extra informatie blijft de enige invoer voor deze functie. Bestaande persoonlijke gegevens worden niet verwijderd.
