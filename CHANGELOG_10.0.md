# Reisblik 10.0 — historisch changelog

Dit bestand is de oorspronkelijke documentatie voor de 10.0-startversie. Zie `CHANGELOG_10.0.3.md` voor de actuele wijziging aan centraal versiebeheer.

## 10.0.6 — JSON persoonlijke gegevens teruglezen
- `Bezocht` leest `personalData.visitedAt` uit de JSON wanneer er geen lokale override bestaat.
- `Extra informatie` toont JSON `personalData.extraInfo` naast lokale notities, ook wanneer localStorage leeg is.
- De JSON blijft de portable bron; lokale gegevens blijven behouden.

## 10.0.8
- Centrale versieweergave en cacheverwijzingen hersteld.
