# Reisblik 9.8.11 — MASTER

## Status

**Reisblik 9.8.11** is de ontwikkelmaster waarin de HTML-export is gecorrigeerd.

De veilige terugvalbasis blijft **Reisblik 9.8.6**.

## Kern van deze versie

De oorspronkelijke voorbeeld-HTML wordt uitsluitend gebruikt als structurele inspiratie voor de reisboek-/tijdschriftopmaak. De gegenereerde HTML bevat geen Japan-specifieke voorbeeldinhoud meer.

De automatische slideshow-layout uit 9.8.10 is behouden. De ondersteunde varianten zijn:

1. 1 foto → één grote foto
2. 2 foto's → naast elkaar
3. 3 portretfoto's → drie naast elkaar
4. 3 landschapsfoto's → twee boven + één grote onder
5. 1 portret + 2 landschappen → portret links + twee rechts
6. 4 foto's → 2 × 2
