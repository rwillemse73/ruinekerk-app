# Reisblik 9.6 – Mijn reisdagboek setup

Deze versie is een eerste technische opzet voor de nieuwe Reisdagboek-functie.

## Gebruik
1. Open **📅 Mijn reisdag**.
2. Kies een periode.
3. Gebruik de bestaande selectie.
4. Kies **📖 Reisdagboek bekijken** voor de nieuwe tussenpagina.
5. **📄 Download DOC** blijft de bestaande Word-export.

De tussenpagina is nadrukkelijk nog geen definitief reisboek. De bedoeling is eerst de basisopmaak en inhoudelijke indeling te testen.
